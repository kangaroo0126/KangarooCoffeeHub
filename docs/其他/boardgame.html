【筆記】 桌遊設計

壹、基礎桌遊概論​

一、什麼是桌遊​

  1. 常見說法：能在桌上玩的遊戲（But 地上玩呢？那筆仙算嗎？麻將呢？）
  2. ＜設計你的第一款桌遊＞之書中定義：透過配件執行規則允許行動的一種娛樂載體
    1. 配件（Components）：棋子、卡片、骰子、板塊、計分板、牌套、玩家面板，現代還有App/數位支援作為配件之一
    2. 規則（Rules）：限制和授權玩家可以做的事（回合結構、勝利條件、資源運作）。
    3. 主題／行動（Theme / Actions）：玩家在系統內執行的行動（移動、交易、建造、推理）。
  3. 桌遊的定義不斷在變化，像是有些需要下載APP。而有些人認為教育桌遊是教具而非桌遊….
  4. 麻將為何不是桌遊呢？
    1. 傳統桌遊是獨立性的，例如：撲克牌、麻將、圍棋，但我們不會說我們玩麻將桌遊
    2. 桌遊是個統稱，底下如：妙語說書人、卡卡頌才是遊戲名稱。與撲克牌那些差異是，當我們說卡卡頌，別人不知道你在說什麼
  5. 桌遊與文化多樣性
    1. 日本：盒裝精美、規則簡約
    2. 歐美：遊戲時間長，Why？
      1. 氣候因素：冬季寒冷，偏好室內活動
      2. Hygge文化：家庭的時光
      3. 社交價值
      4. 地理條件：地廣人稀、增強社交需求

二、神秘桌遊公式：（機制＋配件）Ｘ黑盒子＝桌遊​

桌遊的玩法是由「機制」發展而來的，而「配件」用來承載玩法，讓玩家可以用它來體驗遊戲

Ａ、遊戲骨架－機制​

  1. 數個桌遊機制＝玩法，例如：
    1. 【玩法】玩家說故事、對談 ⇒ 【機制】說故事、溝通限制
    2. 【玩法】透過出牌攻擊彼此 ⇒【機制】互相攻擊、玩家移除
  2. 桌遊設計不再於機制本身，而是玩法的體驗，因此可以結合多種機制，玩出新玩法。而機制就像齒輪，想給玩家的感受、體驗呈現出來。
  3. 方法論：對遊戲的玩法或想像目標前進 → 挑選適合的桌遊機制 → 找到機制間有趣組合 → 加入創意，讓遊戲有變化
  4. 推薦網站：桌遊機制大全列表
    1. 桌遊的維基百科：BoardGameGeek
    2. 桌遊設計實戰Book

Ｂ、遊戲肉身－配件​

  1. 需要題目牌的桌遊：可規劃不同難度題目、顏色區分難易度
  2. 若較為複雜規則，可以設計玩家的幫助卡
  1. 配件種類：卡牌、骰子、米寶（人頭）、板塊（小塊厚紙板）、圖板、指示物（如：代幣、方塊、旗子、小寶石）
  2. 若配件的美術設計不夠獨特、美觀或有趣，這款桌遊容易被錯過

Ｃ、遊戲靈魂－黑盒子(規則、判定、行動)​

  1. 第一種：加入其他遊戲玩法機制
    1. 例如：原本只有畫畫的機制，現在再加上投票機制
    2. 比較
      1. 桌遊機制：遊戲設置、遊戲玩法、行動方式、遊戲目標
      2. 遊戲玩法機制：桌遊機制中的其中一種類別，決定桌遊的玩法
  2. 第二種：全新創意
  3. 從機制作為出發點，再將機制發想成玩法

三、桌遊種類－以用途區分​

  1. 娛樂遊戲：帶來歡樂
  2. 教育遊戲：帶來知識或能力。例如：程式教育＜海霸＞、臺灣歷史＜走過台灣＞
  3. 議題遊戲：玩家感受與反思事件。例如：＜烏托邦賽局＞體驗小型社會，感受世代交替與階層 => 無正確答案、著重於促進玩家討論，以提升對於議題的意識

四、桌遊的四個好處​

  1. 透過包裝引起學習動機－設計桌遊簡易流程：

    Step 1 ：設定學習目標
    －請勿把目標直接呈現在遊戲中，例如透過將題目做成一張張的卡牌
    －娛樂桌遊也可以有學習目標，例如：培養溝通能力
    Step 2：重新包裝流程（將知識納入玩法與流程中）
    Step 3：加入其他元素（遊戲 vs 學習目標找到平衡）

  2. 有環境可以嘗試錯誤
  3. 煮到自己的學習過程，透過遊戲連結知識
  4. 轉念 ⇒必須做到的事情變成想做的事情

五、設計桌遊的心態​

  1. 桌遊不是萬靈丹
    1. 勿把每個知識/學科變成桌遊，因為各自有各自適合的傳遞方式
    2. 能帶來的效益有限 ⇒ 思維仍停留在遊戲情境中，仍需教師帶領反思才能與現實連結
      1. 在遊戲中學習Game-Base Learning：將遊戲或遊戲概念融入學習過程（作為課前引導或是課後複習）
      2. 面對面的真實互動
      3. 跨界媒材轉化桌遊
  2. 設計無法一次到位
  3. 沒有最好的桌遊，只有適合的桌遊
  4. 一切都是體驗，遊戲只是手段：設計桌遊時，「成效」很重要 ⇒ 在遊戲中想要實現【某成效】，所以我想試試【某玩法】

貳、桌遊設計心法​

六、設計桌遊前的思考​

  1. 設計桌遊前第一步：**這款桌遊傳遞什麼訊息？**至少要有一個目的。
    1. 玩家透過這款桌遊獲得怎樣的情緒、感受或體驗？
    2. 玩家玩完桌遊後，得到什麼呢？
  2. 考慮桌遊的傳遞方式（玩法）⇒ 玩家獲取桌遊背後意義的主要橋梁
    1. 玩法是提升玩家的體驗，而非為了遊戲而設計
  3. 設計桌遊前第二步：重點並非遊戲，而是玩家可獲得什麼？⇒ 所有思考都圍繞在「體驗」上！（包含卡牌、美術與配件）
  4. 設計桌遊前第三步：描繪未來主要受眾
    1. 清楚設計的主要底線，哪些事情不能碰。如：遊戲時間不可超過半小時
    2. 思考主要受眾的樣貌，定後續的設計底線與方向
  5. 設計桌遊前的三大考量
    1. 時間：願意花多少時間在設計桌遊上
    2. 能力：自身能力是否能在時間內設計與應用
    3. 金錢：願意花多少費用在製作與印刷

七、開始設計桌遊（想法→機制→玩法）​

【Step 1：從現實到遊戲】​

  1. 先決定桌遊種類：娛樂/教育/議題桌遊
  2. 發想桌遊的學習目標或帶給玩家的體驗
    1. 玩家能獲得什麼？
      1. 教育／議題 ⇒ 知識
      2. 娛樂 ⇒ 樂趣
    2. 發想學習目標時，將敘述拆成多個元素，每個元素有一個詞彙（發散）
  3. 篩選 1~3 個元素，成為此款桌遊要帶給玩家主要的知識或體驗（收斂）
  4. 根據上述所選定的元素，用一句話說明學習目標與體驗。例如：我希望玩家可以在遊戲中做XXX，並在玩完後獲得XXX。
    1. 將所選取的元素串聯起來，轉化成簡單的遊戲流程（=脈絡）

      舉例：
      1.問題意識：許多人不擅長辨識情緒 ⇒ 設計教育桌遊，讓玩家可以辨識情緒
      2.設計目標：認識不同情緒，學習表達自己的情緒
      3.元素：針對情緒進行聯想，例如：【種類】、【表達】、【來源】、【判別】、【正反面】，都能成為元素
      4.選取的元素：種類、表達
      5.元素串聯：玩家在遊戲中透過某種方式表達隨機得到的情緒牌卡，並讓他人猜測玩家抽到的牌卡是什麼？藉由這樣玩法， 讓玩家能認識不同情緒種類以及學習如何表達不同情緒

【Step 2：用遊戲玩法機制承載玩法構想】​

  1. 再次核對主要桌遊目標
  2. 針對主要的桌遊目標，發想或挑選「任何」可能的遊戲玩法「機制」，可能是動詞或名詞
    1. 盡可能挑選越多桌遊機制，再逐步篩選適合的
      1. 因為現在選用的機制不一定會用到最後
      2. 不要看到一個機制後停止發想，會扼殺創意
    2. 不要相信自己的直覺，把第一個決定丟到一旁，第二個決定才是創意的開始（要刻意違背大腦的懶惰機制）
    3. 桌遊機制並非越多越好，也要注意數量，因為越多機制代表難度越高
    4. 機制是遊戲大綱，僅提供後續的設計方向。例如：挑選記憶機制的桌遊，後續要思考要用什麼類型的記憶方式？
  3. 從挑選出來的選項，選出1~2個最適合的：一定要再回去思考主要目標，這些機制如何能傳遞你想要的體驗
  4. 將最後決定的玩法機制，統整成一句流暢語句
    1. 單調很正常，此階段僅構思核心玩法即可
    2. 為何是從機制到玩法開始？？
      1. 機制是最有立即效益的做法
      2. 降低設計門檻 例如：設計一款能引起玩家熱烈討論的桌遊（好像有點難）
        設計一款結合玩家投票的機制，讓玩家可以熱烈討論（好像簡單很多）
    3. 關鍵：先組合機制再發揮創意

🎇小提醒：挑選機制並非在設計桌遊，而是在決定玩法的走向而已

【Step ３：搭建玩遊戲核心後，再往外擴散】​

  1. 清楚定義與建構遊戲的完整藍圖（線性發展 ⇒ 主要流程與遊戲核心機制）

    • 核心機制：代表一款桌遊最主要的玩法。例如：妙語說書人的核心機制是說故事。
    • 如何判斷：移除某一個機制後，看看遊戲是否可以進行
    規則結構說明例子
    遊戲設置遊戲開始前，如何設置檯面或拿取起始物？設置共用卡牌桌面，分配數張守賠給玩家
    遊戲流程每個回合玩家要做什麼行動？有哪些判定？ ⇒ 遊戲玩法+遊戲行動 ⇒ 玩家可以執行的事情輪到自己的回合時，需抽一張題目卡，並開始演戲讓別人猜
    遊戲目標遊戲會在甚麼目標觸發結束，並決定贏家當有一位玩家達到５分時，即成為贏家

  2. 輔助機制：一款桌遊的輔助玩法 ⇒ 輔助機制是增加趣味性，提供多樣玩法，而非偏離遊戲重心

    例如：＜獨家暗語＞為例。
    核心機制 ⇒ 關鍵線索玩法就是依據關鍵線索，玩家去猜出題目。⇒ But 太單調
    加入輔助機制 ⇒「不能重複！」。玩家寫下關鍵線索，並公開，若與他人重複就必須擦掉。

  3. 誰是核心機制？誰是輔助機制？由桌遊設計師自己決定

【Step ４：將零碎的想法條列出來】​

  1. 收斂思考，統整目前想法 ⇒ 結構化、條件化
  2. 機制段捨離（若有更好的，就果斷地放棄或更新機制）
  3. 條列規則的目的 ⇒ 做初步的檢查！！！
    1. 遊戲名稱、介紹、目標、配件、設置、進行、結束、常見問題與其他內容（進階玩法、卡牌介紹…）

八、開始測試桌遊​

測試前小提醒：
製作桌遊雛形，請放棄完美（完成主義>>>>完美主義） ⇒ 因為可能需要打掉重練，建議在第二輪、第三輪調整後，再投入更多精力設計卡牌與配件

  1. 先進行內部測試後，再進行外部測試

    1. 內部測試：找出遊戲大問題
      1. 參與人員：有設計桌遊流程的夥伴
      2. 測試目標：找出遊戲大問題、確認流程順暢度、確認遊戲體驗是否符合預期
      3. 若測試過程中，已明顯發生存在的問題，可以立即調整
    2. 外部測試：確認遊戲完成度
      1. 參與人員：沒參與桌遊設計的夥伴，如家人、朋友
      2. 測試目標：確認桌遊是否夠成熟（大眾接受度、以及是否能獨立理解規則）

  2. 接納必要的回饋，但是不是所有回饋都照單全收 ⇒ 審視建議是否值得參考

    1. 是否是回饋者的主觀願望
    2. 一定要回到設計初衷

  3. 用三個策略檢查你的遊戲好不好玩

    1. 足夠的【互動】
      1. 互動方式：聊天、合作
      2. 機制之間的搭配、偶爾的驚喜或是特殊少見的互動方式，都可以讓桌遊變有趣
    2. 漸進的【成就】
      1. 成就感＝目標設定＋難度控制
      2. 能感受到刺激挑戰，但不會失去信心
    3. 適度的【變化】 ⇒ 創造驚喜感
      1. 變化不可以太頻繁
      2. 例如：事件卡引入突發事件、運用骰子，根據觸發點數執行對應行動、隨機抽牌
    4. 遊戲方向也很重要
      1. 方向指的是「遊戲體驗」（玩家感受與獲得什麼）

    一款桌遊，無法滿足所有人，自己喜歡，有達成預設目標，一些人喜歡就足矣了

參、桌遊發想到實際商品​

九、設計後的大小事：想要公開販售桌遊嗎？​

  1. 玩法設計好後的苦功
    1. 對遊戲做最後調整：包含規則書的編輯、玩法調整與確認、規劃桌遊的配件與規格 （像是一些桌遊常見用語：牌庫、牌池、面朝上／下、回合、輸、局
    2. 美術編輯：排版整齊與易讀性
      1. 要有直觀的圖示設計，不要讓使用者看到卡牌都需要去翻規則說明書。例如：金色-金幣
      2. 模仿是學習的開始（但不是抄襲），例如：字體間距、字型、圖案樣式
  2. 自己出版 vs 找出版社？
    出版社出版自己出版
    優點1會協助美術設計、遊戲編輯…利潤自己獲取
    優點2有既有的銷售管道與行銷資源可以學習所有事物
    缺點利潤會被稀釋萬事得自己來，如：銷售、印刷、客服…

十、透過群眾募資，把桌遊賣出去​

  1. 群眾募資 ⇒ 另類的預購，贊助人先提供資助資金，之後再把產品賣給你。提案者會設立一個目標金額。達到門檻才會開始交付產品，否則金額會退還給贊助人手中
  2. 臺灣群眾募資：
    1. 嘖嘖 zeczec：https://www.zeczec.com/
    2. 挖貝：https://wabay.tw/?context=header&locale=zh-TW
    3. Flying V：https://www.flyingv.cc/
  3. 為何要使用群眾募資：
    1. 資金籌備：提案者可以透過贊助者的資金，來支付開發成本
    2. 市場驗證：藉由消費者回饋與意見，了解市場需求
    3. 專案曝光
    4. 建立第一批支持者社群
  4. 群眾募資準備三要素：網站、文案、影片
    1. 最好的方式是透過圖片傳達
    2. 重要性：文案>>>產品
    3. 文案考驗說故事能力
    4. 募資文案撰寫策略
      1. 產品特色：用一句話精美圖片抓住目光
      2. 現實問題：顧客在意的現實問題，引起目光與共鳴，感受產品必要性
      3. 提出解方：介紹自己的產品如何解決顧客的問題
      4. 細節介紹：包含內容物、玩法、願景….等。不要開頭文案就說細節，而是先吸引顧客產生興趣
      5. 使用回饋：邀請幾名參與者遊玩，並轉寫心得
      6. 贊助方案：寫清楚方案內容與費用
      7. 團隊與其他
