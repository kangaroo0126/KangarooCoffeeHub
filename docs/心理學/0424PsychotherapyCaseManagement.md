# 0424 心療個管的分化與合作：分裂的不是系統，而是焦慮找不到地方放？
> 講者：辛昱融 諮商心理師

![](/img/blog/psy03.png)

## 壹、重點筆記

### 一、 個案管理的基礎模式與功能
- **模式與分工： 區分為「個案管理師 (個管)」與「晤談人員 (心理師)」**。 
- **核心功能：**
    - **資源連結與轉介：** 包含連結校內外資源、轉介醫療系統。
    - **心理衛生教育：** 對個案及系統人員進行衛教。
    - **法律與責任：** 執行責任通報。
    - **移除阻礙：** 協助個案去除進入諮商過程中的各種障礙。
- **適用對象：** 所有個案皆可納入，但強調**危機個案、困難個案及高風險個案**的需求。

### 二、 大專輔導人員的現實挑戰
- **角色期待與現實的落差：** 輔導人員常被期待擔任第一線談判高手、處理偏差行為，甚至被要求「談一次就要轉好」或「轉介後就不關原單位的事」。
- **多重困難：**
    - 無法拒絕服務，特別是高風險個案。
    - 面對長官焦慮時，需時時掌握個案狀況的壓力。
    - 缺乏足夠的保護機制與對等的合作關係。

### 三、 系統合作與「分化」現象
- **內外系統範疇：** 涵蓋個管與個管之間、個管與心理師、校內各單位（如教官、宿舍老師、資源教室），以及校外系統（家庭、醫院、衛政/社政單位）。
- **分化的成因與影響：**
    - 當焦慮找不到出口時，系統往往會產生「分化」而非合作。
    - **專業立場被削弱：** 內外單位人員若不了解個案特性，可能會質疑輔導人員的界線。
    - **缺乏共識：** 諮商單位內部若對處遇無共識，會增加系統壓力和焦慮。
    - **角色切分：** 輔導人員需在行政腦與個管腦之間轉換，並在個案、家長與導師的不同說法中尋求平衡。

### 四、 跨單位會議與自我照顧
- **跨單位會議功能：** 旨在建立內部共識與外部合作分工，並釐清家庭功能，讓家庭負起責任。
- **資源盤點要素：** 必須建立在**信任、安全與支持**的基礎上。
- **輔導員的自我調適：** 需注意「替代性創傷」、「同理心疲勞」與「耗竭」問題，學校應建立校內外督導機制及支持網。

## 貳、案例分享：

**【案情描述】**
一名個案目前正在接受諮商，但出現了以下狀況：
1. **拒絕個管：** 個案明確表示無法與個案管理師合作。
2. **更換心理師要求：** 個案不願意繼續跟原本的心理師晤談，並強烈要求更換成「實習心理師」。
3. **情緒勒索：** 個案採取極端手段，威脅輔導人員若不完成其訴求（即更換心理師），就要進行**自我傷害**。

**【案例分析與反思】**
這個案例呈現了多個核心議題：
- **界線的考驗：** 個案試圖透過自我傷害來突破諮商的制度與界線。
- **系統分化：** 當個案指定特定對象（實習心理師）時，可能會造成諮商單位內部對於處遇方式的歧見。
- **安全與支持：** 輔導人員需評估：此時「順從個案」是提供支持，還是反而成為個案進入諮商的阻礙？如何在確保個案安全的前提下，維持專業立場而不被個案的焦慮/威脅所「分化」？
