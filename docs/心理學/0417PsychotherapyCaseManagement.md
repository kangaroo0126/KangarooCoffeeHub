# 0417 心療個管的挫折時刻：誰的挫折？如何解決？

> 講者：陳冠宇 精神科醫師

![](/img/blog/psy02.png)

## 引言：案例
李心理師是一位充滿熱誠的新進心理師（**高責任感與完美主義者**）。   
**過程**：他接案了一位長期自傷且挑戰權威的個案。個案常在半夜傳訊息表示想輕生（**受害者**），李心理師擔心出事，犧牲睡眠回訊安撫（**拯救者**）。某次，李心理師因勞累漏掉一則訊息，個案在會談時憤怒指責他「根本不專業、想害死我」（**個案轉為迫害者，心理師淪為受害者**）。   
**結局**：李心理師感到極度挫敗、失眠且開始懷疑自己不適合這行（**職業倦怠**）。  

## 一、 職業倦怠（Burnout）與系統性挫折
1. **職業倦怠的定義**：包含**情緒耗竭、去人格化（對工作冷漠疏離）及成就感低落**。
2. **高危險群與症狀**：**高責任感與完美主義者最容易中招，表現出易怒、無助、失眠或肌肉痠痛。**
3. **挫折的四個層次**：
![](/img/blog/0417-1.png)
- **個人層次**：覺得自己勝任能力不足。
- **單位/機構層次**：無法對長官交代或輔導政策失敗。
- **社會層次**：社會安全網破洞，一線工作者淪為系統的「替罪羔羊」。
- **資源困境**：台灣每人每年的心理健康預算不到 19 元，這反映了資源投入與大眾期待間的巨大落差。

> 舉例：當一名社工處理家暴案失敗時，媒體大肆批評社工失職，這就是系統將一線人員視為「替罪羔羊」的現實縮影。

## 二、 溝通陷阱：心理遊戲【艾瑞克·伯恩（Eric Berne）】與戲劇三角
1. **心理遊戲公式 (G Formula)**：餌 + 鉤 = 反應 — 轉換 — 混亂 — 結局（結局永遠是大家都不舒服）。
![](/img/blog/0417-2.png)

2. **Karpman 戲劇三角**：
    - **受害者**：展現無能、可憐，吸引他人幫助。
    - **拯救者**：過度熱心、犧牲自我，試圖解決他人問題。
    - **迫害者**：習慣性指責、控制，維護自我價值感。
![](/img/blog/0417-3.png)

3. **角色轉換**：遊戲中角色會不斷切換。例如：媳婦受委屈（受害者），鄰居幫忙（拯救者），若媳婦後來反向攻擊鄰居多管閒事，鄰居便成了受害者。

## 三、 助人者的暗影
1. **助人者症候群 (Super-Helper Syndrome)**：難以拒絕他人、過度犧牲自我需求，試圖透過幫助人來證明自己是「好人」。
2. **自我受害者化 (Self-victimization)**：
    - **特徵**：推卸責任、尋求關注、展現「道德精英主義」（覺得自己最可憐也最高尚）。
    - **後果**：失去生活掌控感，阻礙個人成長。

## 四、 如何解套：解決方案與轉化策略

### 1. 減少心理遊戲的原則
- **自我覺察**：辨識自己是否進入了戲劇三角。
- **勇敢表達**：說出真實感受，不漠視能力。
### 2. 成為倡議者 (Advocacy)
- **定義**：為特定議題發聲，推動政策與制度變革。
- **區別**：倡議是長期的策略行動，而不僅是短期的抗議。
### 3. 團隊合作與團療因子
- **孤軍奮戰易自憐**：強調團隊支持能避免受害者情結。
- **Yalom 團療因子**：如「普遍性」（發現自己不孤獨）、「利他主義」（透過付出而獲得）及「團體凝聚力」。
### 4. 全方位自我照顧：薩提爾的「自我曼陀羅」 (Self Mandala)
- **生理與感官**：透過**腹式呼吸**（啟動副交感神經）、睡眠衛生、控制 3C 藍光來放鬆。
- **營養**：遵循「七分飽」、「少油鹽糖」與「享受飲食」的原則。
- **情緒與理智**：覺察接納情緒，並透過讀書、聽演講持續理智成長。
- **親密關係**：建立**心理界線**與責任底限。
- **靈性發展**：定義為「自我超越以發現生命意義」。這包含宗教信仰帶來的心理平靜，以及**高峰經驗**（如在自然美景、音樂中感受到極度和諧與敬畏的瞬間）。
