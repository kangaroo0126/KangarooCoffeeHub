# 筆電耗電超快？教你用 Windows 內建指令 3 秒查出電池健康度與耗損！
![](/img/blog/battery.png)

是不是有時候會發現，明明筆電才剛充飽電，電量卻還是消耗得特別快……

甚至開啟了「節能模式」，還是覺得電量下降速度驚人……

近期我那台已經使用兩年多的筆電，也開始頻繁出現這樣的情況，導致每次出門都得隨身攜帶充電器。

但你知道嗎？其實我們可以透過簡單的方法，檢測筆電電池的耗損程度與健康狀況。

接下來，就來為大家介紹，如何在自己的筆電中查看電池健康度吧！

（以下以Windows系統來做說明。）

## 一、生成電池健康報告

1. **開啟「終端機」或「powerShell」，並輸入以下指令**

```jsx
powercfg /batteryreport /output C:\battery_report.html
```

2. **此指令有三個部分，分別說明如下：**
- 程式名稱－powercfg：全名是 **Power Configuration（電源設定工具），** 是專門負責管理電源、電池相關的功能
- 功能參數－ /batteryreport：這是給 powercfg 的**指示**，告訴它要做什麼事。`/batteryreport` 的意思是「幫我產生一份電池報告」
- 額外參數（存到哪裡，可以自行更改）－output C:\battery_report.html
    
    > *存到 C:\ 根目錄可避免因 OneDrive 同步或帳號路徑問題導致找不到檔案。*
    > 
    > 若要存到桌面且避免路徑問題，建議使用以下更穩定的寫法：  
    > `$desk = [Environment]::GetFolderPath("Desktop")  
    >
    > powercfg /batteryreport /output "$desk\battery_report.html"  
    >
    > start "$desk\battery_report.html"`  
    >

因此，整句話的意思是「請執行電源管理程式，幫我產生一份電池報告，並且把它存到C槽，檔名叫做 battery_report.html」

3. **並再次輸入以下指令，以開啟電池健康報告位置**

```jsx
start C:\battery_report.html
```

## 二、電池健康報告數據解讀

### **1.關鍵數值解析**

| **數值名稱** | **單位** | **意義與判讀** |
| --- | --- | --- |
| DesignedCapacity | mWh | **出廠設計容量，不會變動，是所有健康度計算的分母基準。** |
| FullChargedCapacity | mWh | **目前電池能充到的最大容量。隨使用時間降低，是衡量耗損最直接的數值。** |
| CycleCount | 次 | 累計完整充放電循環次數（0→100% 算一次）。越低代表電池越新。 |
| EstimatedChargeRemaining | % | 當前剩餘電量百分比，不代表健康狀態。 |
| EstimatedRunTime | 分鐘 | 預估剩餘使用時間。電池老化後此數值會明顯縮短。 |
| BatteryStatus | 代碼 | 1 = 放電中、2 = 充電中、3 = 充飽、4 = 低電量、5 = 嚴重低電量。 |

### **2.健康度計算機**

> **健康度 (%) = FullChargedCapacity ÷ DesignedCapacity × 100**
> 

#### **2-1 健康度判斷標準**

| **健康度** | **狀態** | **建議行動** |
| --- | --- | --- |
| 95 – 100% | **優良** 全新狀態 | 正常使用，無需特別注意 |
| 85 – 94% | **良好** 輕微耗損 | 正常使用，屬自然老化範圍 |
| 75 – 84% | **注意** 輕度耗損 | 開始留意，定期用 batteryreport 監控 |
| 60 – 74% | **警告** 中度耗損 | 續航明顯縮短，考慮更換計畫 |
| 40 – 59% | **危險** 嚴重耗損 | 強烈建議更換電池 |
| < 40% | **極危** 嚴重老化 | 立即更換，留意是否有膨脹跡象 |

#### **2-2 循環次數（CycleCount）判斷**

| **次數** | **狀態** | **說明** |
| --- | --- | --- |
| 0 – 300 | **優良** | 近全新，容量損耗極少 |
| 300 – 500 | **良好** | 正常日常累積，可接受 |
| 500 – 800 | **注意** | 明顯老化，可感覺到續航縮短 |
| 800 – 1000 | **警告** | 接近壽命門檻，準備更換 |
| 1000+ | **危險** | 超過設計壽命，強烈建議更換 |

## 三、**延長電池壽命的建議**

| **建議做法** | **原因** |
| --- | --- |
| 保持電量在 20%–80% 之間 | 鋰電池在此區間電化學壓力最低，老化最慢 |
| 避免長期插電維持在 100% | 高電位狀態加速正極材料退化 |
| 避免電量歸零再充電 | 過放損傷電芯，BMS 可能鎖定電池 |
| 注意散熱，避免高溫環境使用 | 溫度每升高 10°C，老化速率約增一倍（Arrhenius 定律） |
| 長期存放時保持 40–60% 電量 | 避免長時間滿電或低電位儲存造成的永久容量損失 |
| 每 3–6 個月執行一次完整充放電 | 重新校正 BMS，讓電量顯示更準確 |
